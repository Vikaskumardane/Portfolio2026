# Vikaskumar Dane | Cloud & DevOps Engineer Portfolio

![Portfolio Preview](https://images.unsplash.com/photo-1555066931-4365d14bab8c?q=80&w=1200&auto=format&fit=crop)

A modern, high-performance personal portfolio built to showcase cloud architecture, DevOps expertise, and full-stack software engineering projects. Designed with a focus on speed, seamless user experience, and robust SEO.

## 🚀 Live Demo
**[vikaskumardev.netlify.app](https://vikaskumardev.netlify.app/)**

## ✨ Key Features

- **Blazing Fast Performance:** Built on Next.js 15 App Router utilizing Server Components to minimize client-side JavaScript.
- **Dynamic Medium Blog Integration:** Automatically fetches and displays the latest Medium articles via RSS in a smooth, zero-JS GPU-accelerated CSS marquee.
- **Consultant-First Layout:** Productized service cards specifically tailored for Cloud, DevOps, and Full-Stack freelance opportunities.
- **Responsive & Accessible:** Mobile-first design using Tailwind CSS v4, ensuring perfect layouts across all devices from phones to ultra-wide monitors.
- **Serverless Contact Form:** Fully functional contact system powered by Web3Forms, delivering messages directly to email without requiring a dedicated backend.
- **SEO Optimized:** Comprehensive metadata configuration, automated `sitemap.xml`, and `robots.txt` for top-tier Google search ranking.
- **Fluid Animations:** Scroll-triggered micro-interactions and page transitions powered by Framer Motion.
- **Dark Mode Support:** Seamless system-synced light/dark mode toggling.

## 🛠️ Technology Stack

- **Framework:** [Next.js 15](https://nextjs.org/) (React 19)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Contact API:** [Web3Forms](https://web3forms.com/)
- **Deployment:** [Netlify](https://www.netlify.com/)

## 💻 Running Locally

To run this project on your local machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Vikaskumardane/Portfolio2026.git
   cd Portfolio2026
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

## 🏗️ Building for Production

To create an optimized production build:

```bash
npm run build
npm run start
```
